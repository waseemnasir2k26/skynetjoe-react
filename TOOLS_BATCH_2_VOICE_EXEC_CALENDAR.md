**Structure:**
1. Hero: badge + headline + 3 stat cards (`4 steps`, `Local-only`, `.md export`).
2. 4-step slide UI with progress bar + reset:
   - **Step 1 — Identity:** 5 fields (Brand name*, Industry, Founder/team size, Target audience*, Origin story textarea). Brand name + audience are required to advance.
   - **Step 2 — Tone sliders:** 8 axes (Formal↔Casual, Serious↔Playful, Reserved↔Bold, Traditional↔Innovative, Detailed↔Concise, Friendly↔Authoritative, Optimistic↔Realistic, Universal↔Niche) — 1–10 each, live label e.g. `bold-leaning`.
   - **Step 3 — Vocabulary:** 3 textareas (Words we USE / AVOID / Signature phrases).
   - **Step 4 — Examples:** 3 textareas (Best writing / Best customer quote / Anti-example).
3. Output panel: 500–800 word generated Brand Voice Profile rendered in `<pre>` (scrollable, 60vh max), 3 buttons (Copy doc, Download .md, Edit). The generated doc includes:
   - Persona summary paragraph
   - Identity block
   - 8-row markdown tone matrix
   - Vocabulary dos/don'ts
   - 5 sample sentence rewrites ("Generic → Your voice") — generated by branching on slider values + injecting signature phrases.
   - Final fenced `system prompt block` ready to paste into Claude/ChatGPT.
4. Sticky bottom CTA card → Cal.com.

**Notable logic:** `buildRewrites()` branches on `concision`, `boldness`, `formality`, `playfulness`, `innovation`, `authority`, `niche` slider values to emit voice-flavored versions of 5 generic sentences. `buildSystemPrompt()` assembles the paste-ready prompt with WRONG / RIGHT example pairs at the end so models match the right column.

## Tool 2 — Executive Summary Generator

**Route:** `/tools/executive-summary-generator`

**Files added:**
- `src/app/tools/executive-summary-generator/page.tsx` — server component.
- `src/app/tools/executive-summary-generator/Generator.tsx` — client.

**Structure:**
1. Hero with 3 stat cards (`Under 2 sec`, `Local-only`, `5 formats`).
2. Input panel:
   - Big textarea (40-char minimum, 8000-char cap, live word + char counter).
   - 3 controls: Audience dropdown (CEO / Investor / Board / Client / Team), Length slider (100–500 words), Tone dropdown (Formal / Direct / Storytelling).
   - Generate button with 900 ms fake-latency loading spinner; Regenerate button after first run.
3. Output panel — 5 tabs:
   - **TL;DR:** 3 ranked bullets, trimmed to ≤24 words each (< 100 words total).
   - **Email-ready:** Subject line (mood-prefixed: `Update` / `Flag` / `Summary` + first noun phrase), 3-paragraph body using tone-aware greeting/signoff and audience-aware CTA.
   - **Slack-ready:** Sentiment emoji header, lead sentence, 4 prefixed bullets (✅/📈/⚠️/👉), thread-prompt close (~150 words).
   - **Deck-ready:** Slide title + 5 numbered bullets, max 14 words each.
   - **Investor 1-pager:** Problem / Solution / Traction (numeric-preference) / Ask (regex-detected) / 3 next-step bullets (future-tense detection).
4. Per-tab: word/char count footer + dedicated Copy button (per-tab clipboard).
5. CTA below output: "Want a REAL AI-powered summary? Book a 30-min call to scope a custom prompt for your workflow." → Cal.com.

**Notable logic (pure-client heuristics — NO LLM):**
- `splitSentences()` lookbehind regex (`(?<=[.!?])\s+(?=[A-Z0-9"'(\[])`).
- `scoreSentence()` weights 26 target keywords (`revenue`, `users`, `churn`, `pipeline`...), 20 positive / 20 negative sentiment words, numerals/percentages bonus, length sweet-spot (8–28 words).
- `extractNounPhrases()` mines capitalised runs of 1–4 tokens, dedupes, ranks by frequency, drops stop-starters.
- `sentiment()` → `positive | neutral | negative` controls Slack emoji + email subject prefix.
- Ranked-then-restored-to-original-order so output flows narratively.

## Tool 3 — 30-Day Content Calendar

**Route:** `/tools/content-calendar`

**Files added:**
- `src/app/tools/content-calendar/page.tsx` — server component.
- `src/app/tools/content-calendar/Calendar.tsx` — client.
- `src/data/content-calendar-ideas.ts` — typed idea bank (19 templates × 4 kinds + platform/goal meta).

**Structure:**
1. Hero with 3 stat cards (`30 days`, `5 platforms`, `3 exports`).
2. Inputs panel:
   - Niche / industry text input.
   - Target audience text input.
   - Goal dropdown (Awareness / Lead-gen / Engagement / Sales / Authority-building) — each ships an `educate/story/proof/cta` mix weight.
   - Start-date picker (default = tomorrow).
   - 5 cadence sliders (0–7 posts/week per platform: LinkedIn / X / Instagram / Shorts/TikTok / Email newsletter).
3. Export bar (4 buttons): **CSV** · **ICS** · **Markdown copy** · **Regenerate** (re-seeds the PRNG).
4. Calendar grid — Mon–Sun rows × 5 weeks (35 cells), each in-range cell colour-coded by platform pills (max 3 visible + "+N more"); today highlighted with cyan border; out-of-range cells dimmed.
5. Click any post pill → modal with: full hook, body angle, suggested CTA, recommended asset (carousel/single/video/email/thread/story), hashtag pills, and a Copy post button.
6. Platform legend bar below grid.
7. CTA: "We'll wire the calendar into your GHL / Buffer / n8n" → Cal.com.

**Notable logic:**
- **Mulberry32 PRNG** seeded from inputs.seed so Regenerate is deterministic / sharable conceptually.
- **Goal-aware idea mix** — `GOAL_META[goal].mix` weights determine probability of pulling from each idea kind.
- **Interpolation** replaces `{niche}`, `{audience}`, `{audienceTag}` (kebab-cased for hashtags), `{n}`, `{n2}`, `{outcome}`, `{action}`, `{month}` (parsed from start-date).
- **Cadence distribution** — for each of 5 weeks, picks N distinct days within the 7-day window without replacement; respects 0 = skip platform entirely.
- **ICS export** is RFC-5545 conformant: VCALENDAR/VEVENT records with UID, DTSTART/DTEND (9:00–9:30 placeholder), escaped commas, multi-line DESCRIPTION via `\\n`.
- **CSV export** has 8 columns: Date / Platform / Kind / Hook / Body angle / CTA / Tags / Asset — proper quoting for embedded commas, quotes, newlines.
- **Markdown export** groups by date with `- [ ]` checklist items, nested body/CTA/tag lines.
