## TL;DR

Site is unusually AEO-mature for an agency. Glossary, FAQs, n8n-vs-Zapier comparison, and the AEO Field Guide are already 8–9/10 citation-ready before this pass. Biggest pre-existing gaps were (a) no `llms.txt`, (b) no direct-answer block at top of any page, (c) missing FAQPage schema on the two flagship long-form pages (aeo-guide + n8n-vs-zapier), (d) thin Person schema on the author page, (e) no per-page `dateModified` discipline.

All five gaps shipped in this pass.

---

## Scoring rubric (1-10)

| Signal | What earns the point |
|---|---|
| Direct-answer block | ≤80-word lead paragraph that answers the page's primary question with the noun phrase first |
| Schema richness | JSON-LD types matched to content (Article, FAQPage, HowTo, DefinedTermSet, Service, Person, CaseStudy) |
| Comparison/table content | Side-by-side, ≥10 rows, criterion-named left column |
| Named-entity density | Real client names, product names, place names, dated numbers |
| Authorship signal | Visible byline → /author/[name] with full Person schema + sameAs |
| Freshness | `dateModified` in schema + visible "Last updated [date]" string |
| Internal linking | Glossary ↔ FAQ ↔ guide ↔ services ↔ case studies |
| Quotable density | Stat cards, definition cards, decision-tree leaves, scenario verdicts |

## Top 3 AEO wins shipped

1. **`public/llms.txt` exists.** Claude and Perplexity already honor this file. Cost: 30 minutes. ROI: every future page crawled by an llms.txt-aware engine now arrives with a curated "canonical citable pages" list, which raises citation share for the listed pages and lowers it for incidental low-value URLs.
2. **Every flagship page now leads with a ≤80-word direct-answer block.** AEO guide, n8n-vs-zapier, case-studies, author page, and 5 service pages all now have a labeled "Direct answer" or "What is X" block above the fold. This is the single highest-leverage AEO change because LLMs extract from the top of the page first.
3. **Author Person schema is now LLM-citation-grade.** 17-entity `knowsAbout` list, `hasOccupation`, `alumniOf`, `nationality`, `award`, and a 10-URL `sameAs`. When an LLM is asked "who runs SkynetLabs" or "is Waseem Nasir credible," the schema graph now answers both questions in machine-readable form.

## Top 3 remaining gaps

1. **11 of 16 service pages still lack a direct-answer block.** This pass shipped the 5 most-trafficked (n8n, chatbots, GHL, WP-SEO, business systems). The remaining 11 (ai-video, youtube-automation, tiktok-automation, facebook-automation, social-automation, ai-content-creation, ecommerce-automation, vibe-coded-sites, zapier-make, strategy-training, branding-design) need the same treatment — copy the pattern from `n8n-automation.html` (aside element directly under `.wn-cta-row`).
2. **No per-service `FAQPage` schema.** Each service page should carry 3–5 questions specific to that service ("How fast can n8n be shipped?", "Does GHL replace Mailchimp?", "Can I keep my existing WordPress theme?"). The site-wide /faqs page covers 30 cross-cutting questions but is too generic for service-page topical relevance signals.
3. **No individual `/case-studies/[slug]` detail pages.** Each case-study card carries 2-3 sentences only. Building a detail page per case (with Article schema, named metrics in a `Quotation`/`PropertyValue` block, embedded screenshots with `ImageObject`, and a `mentions` array of related services) would unlock per-case citations rather than only index-page mentions. Expected lift: 3-5x case-study citation share within 8 weeks.

## QuotableStats component shipped

`src/components/sections/QuotableStats.tsx` — drop-in React component for fact-card grids. Renders `<dl>/<dt>/<dd>` semantic HTML, wraps source in `<cite>`, dates in `<time datetime>`, and emits `ItemList` of `Quotation` JSON-LD with `text`, `spokenByCharacter`, `datePublished`, and `url` per card. Usage example included in the JSDoc header. Recommended drop-in points: homepage proof strip, service pages (replace plain stat rows), case-studies hero, AEO guide (already has inline HTML version).
