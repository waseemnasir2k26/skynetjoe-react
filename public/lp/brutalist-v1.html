// faq

The questions that come up on every intro call.

q / 01 · security

Is the stack SOC2 compliant?

We deploy on SOC2 Type II infrastructure — AWS, Vercel, Supabase. Your tenant data is row-level isolated with Postgres RLS. We provide audit logs and a SIG-Lite questionnaire on request. Full SOC2 audit support ships on the enterprise tier (BYO-cloud, your VPC).
q / 02 · latency

What is the typical response latency?

Median 12ms on cached intents, 380ms on cold LLM calls (Claude Haiku), 1.2s on tool-use loops with database reads. We benchmark p50 / p95 / p99 weekly and ship a Grafana board with the stack.
q / 03 · multi-tenant

How does multi-tenant isolation work?

Per-tenant Postgres schemas with RLS policies enforced at the connection level. Per-tenant LLM API keys (BYO Anthropic / OpenAI / Bedrock — never pooled). Embeddings stored in tenant-scoped pgvector tables. No shared session context. Cross-tenant queries return zero rows by default — they fail closed.
q / 04 · churn

How does this affect day-7 activation?

Across 12 SaaS deployments, the onboarding agent lifts day-7 activation by 18-32% over static flows. The mechanism: it detects intent in the first 90 seconds, surfaces the aha-moment that matches that intent, and flags accounts that drift to your CS Slack with one-click recovery actions.
q / 05 · migration

Do you replace Intercom or sit alongside?

Both. Replace mode kills the existing tool (saves $400-2000/mo) and migrates ticket history into our store. Co-pilot mode runs as a deflection layer in front of Intercom/Zendesk — only escalates the 32% that need a human. Migration tools and history importer included on the Stack tier.
