Questions

What founders ask before signing

Do you work in our n8n instance or yours?
Always yours. We never lock work inside an account we control. If you self-host on Hetzner or Hostinger VPS, we work there. If you're on n8n.cloud, we work there. You own the credentials, the workflows, and the export the day we deliver.
What if Zapier is already half-working — do we have to migrate?
Not on day one. We usually leave existing Zaps alone, build the new logic in n8n, and migrate one Zap at a time once each n8n flow has run clean for two weeks. Migration usually pays for itself on Zap tier savings inside 90 days.
How do you handle credentials and API keys?
We use a shared 1Password vault you control, or your own KMS. Keys live in n8n's encrypted credential store, never in a Sheet. We rotate after handoff and document which scopes each key actually needs.
Can we add AI to an existing workflow instead of rebuilding?
Yes — that's actually our most common engagement. We bolt a GPT-4o or Claude classifier onto your existing form-to-CRM pipe, you get smarter routing in three days, and we don't touch the parts that already work.
What's the smallest project worth doing with you?
$750 single workflow. If your job is one trigger and two actions, you don't need an agency — use Zapier's free tier. If you need conditional logic, retries, an AI layer, or you're paying $79/month for a Zapier tier you've outgrown, that's where we earn the fee back.
