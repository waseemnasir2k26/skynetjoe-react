FAQ

Are these n8n workflows really free?

Yes. Each workflow is a free JSON file in a public GitHub repo under an MIT licence. You import it into your own n8n. You only pay for the accounts it connects to, such as Twilio for texts or a Groq key for the AI step.

Will anything send messages when I import one?

No. The workflows import inactive, and every send node ships disabled. Run it by hand first, check the output, and then turn on the send step. Most of them also cap each run at 50 items.

Do I need to know how to code?

No. You import the file, connect your own accounts, swap the placeholder sheet and phone numbers, and test with your own address. If you would rather not touch it, SkynetLabs can build and run it for you.
